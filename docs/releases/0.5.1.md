# 0.5.1 冻结说明

日期：2026-10-05。冻结范围：现有桌面软件、算法源码、CLI、测试、Kaggle 构建工具与交付文档。

## 交付组成

- `xiyuan-source-0.5.1.zip`：指定提交的源码，含逐文件清单。
- `xiyuan_stitch-0.5.1-py3-none-any.whl`：桌面核心 Python 包。
- `xiyuan-windows-ai-0.5.1.zip`：Windows x64 CPU AI 客户端、模型及演示输入。
- `verification-0.5.1.zip`：该版本验证记录。
- `release-manifest.json`、`SHA256SUMS.txt`：提交身份及文件校验。

实际测试结论以 Release 随附记录及 GitHub Actions 为准。旧版本的源码包、桌面包和实验包不混入该发布。

## 冻结范围之外

本版没有新增用户功能或申请付费算力。历史 0.5.0 质量数据不改写为 0.5.1 结果；其他电脑真人验收、人工盲评、结题报告及原生 8 GB 显卡验证仍未完成。本次发布不等同于项目最终结题。
