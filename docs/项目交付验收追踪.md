# 项目交付验收追踪

更新：2026-10-05。当前冻结基线：0.5.1。

## 当前范围

桌面、源码、wheel、发布文档统一为 0.5.1，并通过 Git 提交、标签、文件哈希关联。发布验证以 GitHub Release 随附证据和 Actions 结果为准。

| 验收项 | 当前状态与证据 | 尚需完成 |
| --- | --- | --- |
| 导入、配准、Mask 编辑、对比、原尺寸导出 | 当前实现及 GUI / CLI 自动测试 | 另一台电脑真人操作验收 |
| LoFTR / RAFT CPU 链路 | 本版发布包四案例离线自检，记录内须为 0.5.1 | 更多实拍场景目视评价 |
| SD / ControlNet / LCM / Hybrid | 已有代码与历史 GPU 实验；本次冻结不新增 GPU 质量证据 | 按冻结快照复核质量与速度结论 |
| 数据、基线和失败案例 | 保留来源、哈希与实验口径；历史 0.5.0 清单另存 | 人工盲评，尤其是无真值实拍照片 |
| 依赖、版本与安装 | 单一版本定义、测试依赖、构建锁、源码 manifest、wheel 独立安装 | 外机真人验收 |

| 财务 | 本次冻结未申请付费算力 | 负责人据票据核实项目历史费用 |

## 历史证据不能替代新版本验收

此前 `deliverables/XiyuanAI` 是旧交付目录。2026-10-05 初次三案例复测不作为 0.5.0 或 0.5.1 最新验收。旧记录保留，不覆盖。

0.5.0 的 116 个回归、64 个单侧受控、16 个双侧变形与 8 组无真值实拍照片仍按原清单解释。16 例中 15 例改善不代表常见照片普遍有效；64 例持平体现保护策略。没有完成人工盲评，不能宣称“至少 70% 案例优于传统方法”。

## 结项判断

版本冻结完成后可作为后续验收的固定对象。项目正式结题仍需真人外机验收、人工评价和最终报告，并如实说明硬件验证边界。
