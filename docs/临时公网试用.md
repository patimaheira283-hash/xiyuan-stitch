# 同学临时试用

公网入口通过 Cloudflare Quick Tunnel 连接本机的分享网关，再访问已有图像实验室。

```text
同学的 HTTPS 浏览器
  → 临时 Cloudflare 地址
  → 127.0.0.1:18768 邀请网关
  → 127.0.0.1:18767 图像实验室
  → 本机后端调用已配置的生图服务
```

## 分享与关闭

把聊天中提供的**完整邀请链接**发给同学，保留末尾 `#invite=...` 部分。网页会自动验证邀请并进入实验室；不会要求同学填写 API key。

有效期默认 24 小时，全部同学共用 30 次生成额度。一次后台接收的生成请求占用一次额度；生成失败也可能有上游用量，因此不会自动返还次数。后端因忙碌或参数检查而拒绝接收的请求不占次数。“仅检查请求”不扣共享次数，也不调用生成服务。

到期后网关拒绝访问，后台程序关闭本次隧道。随时双击根目录 **关闭临时公网访问.bat** 可提前结束共享，原本机网页保持运行。

查看当前链接、剩余额度和到期时间：

```powershell
.\.venv\Scripts\python.exe -m gpt_fusion_mvp.share status
```

电脑需要保持开机、联网，避免睡眠，并保持本机实验服务运行。临时地址服务没有长期可用性保证，适合同学试用。

## 同学可使用的功能

611 对素材、来源与搜索筛选、上传两张自己的照片、编辑融合要求、请求检查、生成和下载图片。

同时只处理一个生成任务，其他人会看到忙碌状态。所有同学可以查看开放前选定的演示结果；开放后新提交的任务和上传图片只向对应浏览器会话展示。清除浏览器 Cookie 或更换浏览器后，新会话不会看到之前的个人试用记录；发起人仍可在本机查看。

## 访问边界

- 邀请码与 API key 无关；它仅用于进入这次临时试用。
- 身份 Cookie 使用 Secure、HttpOnly、SameSite=Strict；提交接口检查来源。
- 未进入试用的访问者只能看到邀请页面，不能取素材索引或提交生成。
- 公网端不提供原始运行 JSON、提示词文件、配置库、工作区目录或服务商配置身份。
- 网关只连接固定的本机实验地址，保留原服务的本机 Host/来源限制。
- 可见数据包含共享素材、来源和选定演示图；个人新任务按会话过滤。

## 本地维护

实现文件：`gpt_fusion_mvp/share.py`；入口页面：`gpt_fusion_mvp/web/join.html`、`join.js`。

本次状态、邀请凭据、次数、会话关联和隧道日志存放在 `outputs/gpt-fusion/shares/<时间>/`。`latest.json` 指向当前共享状态。该目录位于项目已忽略的 `outputs/` 内。不要把这些运行状态文件当源代码公开上传。

重新开放时先确认旧入口已关闭，再初始化并以后台进程启动：

```powershell
.\.venv\Scripts\python.exe -m gpt_fusion_mvp.share prepare --hours 24 --limit 30
# 上一步输出 state.json 的绝对路径，交给 host --state 参数。
```

验证覆盖邀请门禁、Cookie 属性、跨浏览器任务隔离、文件访问范围、总次数限制、超时预留次数、到期与手动关闭。相关测试为 `tests/test_gpt_share.py`，加上原 MVP 测试共 17 项。
