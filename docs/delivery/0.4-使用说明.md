# 0.4 清晰融合 · 使用与复现

解压 `xiyuan-windows-ai-0.4.0.zip`，运行 `XiyuanAI/XiyuanAI.exe`。整个文件夹必须保留。LoFTR 和 RAFT 权重已包含，模型版本与许可证沿用第三方材料清单。软件还提供无需模型的 SIFT 配准。

1. 导入有重叠的图片 A、B，保留默认勾选的“清晰融合”。
2. 点击“自动配准与融合”，查看“清晰融合 / 修复底图”。状态栏会说明优先选用了哪张原图的纹理，或者保持原有融合。
3. 点击顶部“导出当前结果”，保存原始画布尺寸 PNG。羽化、泊松对比页也可以分别导出。
4. 需要进一步处理接缝时，打开“接缝编辑”，使用画笔和橡皮，再选择本机结构修复或免费 GPU 生成修复。各结果单独保留，可比较后选择。

清晰融合是传统图像处理，作用于整个重叠区域；不需要点击 AI 修复才能得到它的结果。它依据两张输入的清晰度、噪声和相互关系选择纹理，参考图只用于实验评分。两图接近或已经对齐时会保留原有融合。它与“实验性颜色 / 局部几何校正”互斥；改变选择后重新配准。

多图仍按相邻重叠顺序导入，清晰融合在每一步拼接中执行。接缝手绘和本机 RAFT 修复的两图限制沿用 0.3；扩散生成仍可使用免费 Kaggle。后续生成不保证改善清晰融合结果，请查看对比图。

## 源码运行

Python 3.12 x64：

```powershell
./scripts/Setup.ps1 -Neural
.venv/Scripts/python.exe -m xiyuan_mvp.gui
.venv/Scripts/python.exe -m xiyuan_mvp.cli data/demo_a.png data/demo_b.png --config configs/clear-cpu.yaml --output-dir outputs/clear-demo
```

`configs/clear-loftr.yaml` 使用 LoFTR 配准，首次源码运行会获取已固定来源的权重；`clear-cpu.yaml` 使用 SIFT。新输出目录中 `06_initial.png` 和最终图为清晰融合结果，羽化、泊松和配准材料另行保存。

## 查看与复现效果

解压 `xiyuan-clear-experiments-0.4.0.zip`，打开 `clear-experiments-0.4.0/index.html`。可切换数据组、方法、完整画布和中心局部；“修正过的退化”保留了旧算法放大噪点的实际结果。表中是全图有效区域指标。

116 个受控案例来自 16 张原始图片，已经用于开发或问题修正，作为回归检查，不能称为 116 个独立实拍或最终盲测。28 个纹理案例使用历史 LoFTR 画布，另外三组使用已知裁剪坐标，单独验证融合。真实照片没有参考全景，不计算伪造的 SSIM / LPIPS。大视差、运动物体、低重叠和错误配准仍需实际查看结果。

```powershell
./scripts/Setup.ps1 -Experiments
.venv/Scripts/python.exe -m scripts.validate_clear_fusion --adaptive --regression --output outputs/my-balanced
.venv/Scripts/python.exe -m scripts.validate_clear_fusion --holdout --regression --output outputs/my-noise
.venv/Scripts/python.exe -m scripts.validate_clear_fusion --fresh --regression --output outputs/my-soft
.venv/Scripts/python.exe -m scripts.high_resolution_acceptance --clear --output outputs/my-4k
```

`--holdout`、`--fresh` 是开发时命名的数据组开关；本版复现须带 `--regression`，不据参数名称宣称数据未被使用。纹理的历史配准基线来自 v4 原始 GPU 实验包；`clear_fusion_experiment.py` 使用该固定几何比较算法。原始实验和当前源码的诊断字段差异在查看器 `raw/executed-source` 中保留了可校验的实际执行代码。

免安装版联合验收命令（在 XiyuanAI 文件夹）：

```powershell
./XiyuanAI.exe --acceptance-data examples --offline --output check/acceptance.json
```

它使用真实 LoFTR、清晰融合和 RAFT，操作导入、导出、鼠标擦除与撤销，检查 Mask 外像素和 PNG。文件选择器由固定路径替代，不是真人现场验收。`--offline` 阻止 Python 网络连接。
