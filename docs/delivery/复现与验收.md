# 复现与验收 · 0.5.1

## 版本与证据

当前基线为 Git 标签 `v0.5.1`。Release 中的 `release-manifest.json` 记录提交、版本和发布文件 SHA256；源码 ZIP 内的 `SOURCE_MANIFEST.json` 记录逐文件哈希。

`verification-0.5.1.zip` 保存单元测试日志、独立安装记录和当前桌面包的离线验收记录。验收中的 `version` 必须等于 0.5.1；`frozen: true` 表示实际运行打包程序。2026-10-05 早先旧目录的三案例自检不作为本版验收。

## 源码测试

Windows x64 / CPython 3.12，在干净检出或源码 ZIP 根目录执行：

```powershell
./scripts/Setup.ps1 -Test
$env:QT_QPA_PLATFORM = 'offscreen'
.venv/Scripts/python.exe -m pytest -q
```

测试不需要云端 API 凭据、真实 GPU 或模型下载。模型替身用于路由和像素约束测试。独立的 GPU 质量实验必须使用真实模型和相应源码快照。

## 免安装包的真实模型验收

进入解压后的 `XiyuanAI` 文件夹：

```powershell
$p = Start-Process -FilePath '.\XiyuanAI.exe' -ArgumentList '--acceptance-data examples --offline --output check/acceptance.json' -PassThru -WindowStyle Hidden
$p.WaitForExit()
if ($p.ExitCode -ne 0) { throw 'Desktop acceptance failed' }
Get-Content -Raw check/acceptance.json
```

应为 0.5.1、`status: passed`、`frozen: true`、`network_blocked: true`、四条通过记录。覆盖真实 LoFTR、RAFT、画笔擦除与撤销、保护开关、Mask 外像素保持、原尺寸导出与运行记录读取。模型验收使用固定文件选择器与 Qt 自动事件，不等于另一台机器上的真人验收。

## 实验结果口径

0.5.0 的 116 个回归、64 个新来源受控、16 个双侧变形及 8 组无真值照片属于历史证据。受控案例不是同等数量的独立实拍；64 例保留底图不等于 64 例改善。没有参考全景的照片不填写伪造的 LPIPS / SSIM。

旧 v1/v2/v3 泊松成绩受 Mask 原地修改影响，不能用于现行比较。v4/v5 使用修正基线。耗时应区分模型加载与推理；T4 的 8 GiB 分配限制不能当作原生 8 GB 消费级显卡实测。

本版冻结没有重跑全套 GPU 质量研究。真人盲评、外机验收、最终研究报告和原生 8 GB 硬件验证仍待后续完成。
