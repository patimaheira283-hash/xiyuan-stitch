# 0.5 结构修复与细节保护

解压 `xiyuan-windows-ai-0.5.0.zip`，运行 `XiyuanAI/XiyuanAI.exe`，保留整个目录。已带 LoFTR、RAFT Large 权重及 CPU 依赖，普通本机操作不需要 NVIDIA GPU。

导入重叠图片 → 自动配准与清晰融合 → 查看底图 → 在“接缝编辑”涂抹需要修复的区域 → 选择“结构修复（本机，两图）”，保留默认“保护清晰细节” → 运行 AI → 比较底图与 AI 结果 → 导出。

生成修复选择 Canny 时，可在“Canny 接缝保护”中选择“原始边缘”“抑制接缝内边缘”或“渐弱接缝边缘”。后两项只改变送入 ControlNet 的接缝区域控制信号，属于待 GPU 对照实验确认的候选；默认仍为“原始边缘”。hybrid 的 GUI 默认混合比例为 5%，这是当前 T4 对照中 LPIPS 最好的保守配置。

“生成取样”可选择“原尺寸重叠分块（实验）”。它把较长接缝切成有重叠的原尺寸 Patch，最后统一合成；会增加 GPU 时间和显存占用，必须与单个 Patch 结果对照后再采用。

“接缝边界保护（实验）”只使用当前输入、Mask 和生成结果检查边界高频突变；如果检测到明显回归，会自动降低 AI 混合比例。它不会读取参考全景。hybrid 默认还会先检查保护性结构修复是否确认有收益，并在残差足够大时才启动扩散生成；“始终生成（对照）”可用于复现实验基线。

状态栏会区分：应用局部错位修复；已有可靠纹理，保留底图；没有确认结构差异减少，保留底图。保护判定只利用输入图片和位移场，不代表所有场景的画质都一定提高。关闭“保护清晰细节”可运行旧版 RAFT 作为对照。两图限制沿用 0.4；多图普通融合仍可使用，扩散生成仍通过 GPU 模式运行。

新增演示：打开运行记录 `examples/motion-run/run.json`，直接运行 AI，可看到双向位移与清晰度引导的结构修复。该示例用 scikit-image 的 NASA astronaut 图片生成局部变形，配准为已知裁剪坐标；它用于展示局部修复，不能当作未知图片自动配准成功的证据。原来的木纹、砖墙和光照示例仍在 examples 中。

## 查看结果与人工评价

打开 `structural-experiments-0.5.0/index.html`。四组数据分开显示：116 个旧案例回归、64 个新来源受控案例、8 组实拍照片、同一预选来源的 16 个双侧变形压力案例。三组受控数据共有 196 例，不等于 196 个独立拍摄场景。

算法在新来源评估前冻结；附加双侧变形实验沿用同一份冻结算法，并非另一批独立素材。8 组真实照片没有参考全景，指标为空。64 个单侧受损案例均保留已有清晰底图；16 个双侧变形案例中 15 例 LPIPS 改善、1 例退化。原始逐例结果包含羽化、泊松、旧版 RAFT；新版不保证胜过所有传统方法。

并行首次运行曾有两例内存分配失败，且有任务中断；改为顺序运行后，同一冻结算法完成全部案例。`failed_attempts` 与运行日志保留初次错误，不将资源失败从历史记录中删除。

勾选“隐藏方法，盲评当前数据组”可随机交换左右方法，记录左侧更好、右侧更好、相当或都不可用。评价保存在本机浏览器，点击“导出我的评价”保存 JSON；尚未进行人的评价，软件不会自动生成评价结论。

## 源码复现

Python 3.12 x64，固定依赖安装方式沿用原说明：

```powershell
./scripts/Setup.ps1 -Experiments
.venv/Scripts/python.exe -m scripts.download_structural_sources
.venv/Scripts/python.exe -m scripts.validate_structural_repair --suite heldout --output outputs/my-050-heldout
.venv/Scripts/python.exe -m scripts.validate_structural_repair --suite joint --output outputs/my-050-joint
.venv/Scripts/python.exe -m scripts.validate_structural_repair --suite real --output outputs/my-050-real
```

逐个执行以控制内存。下载脚本只获取来源清单中固定提交的 16 张公开研究图片，并校验 SHA256；保留上游来源及许可证说明。每次使用新的输出目录；因中断需要续跑时加 `--resume`，续跑会检查冻结算法哈希并保留已记录的失败。

旧 116 例回归需要前版 v4 实验包中的几何记录。完整新查看器构建也依赖四组运行输出。新来源评估可以直接按以上命令单独复现。

## 软件自检

在免安装文件夹运行：

```powershell
./XiyuanAI.exe --acceptance-data examples --offline --output check/acceptance.json
```

检查三组 LoFTR 导入、接缝编辑与导出，以及新增已知几何示例的真实 RAFT 推理、保护开关和像素保持。文件选择器使用固定路径，是自动化桌面验收，不替代他人在另一台电脑上的真人验收。
当前清晰度差异门槛为 1.05；差异不足时保留羽化融合。该判断只使用输入图和 Mask，不读取参考图。

当前版本还会识别主要由平滑光照变化造成的差异；这类差异不会被误当成清晰纹理来源。
