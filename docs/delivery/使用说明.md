# 使用说明 · 0.5.1

当前统一版本为 0.5.1。窗口标题与 `python -m xiyuan_mvp.cli --version` 可确认版本。旧的 `deliverables/XiyuanAI` 目录属于历史交付，不作为本版入口。

## 安装与启动

免安装版：解压 `xiyuan-windows-ai-0.5.1.zip`，双击 `XiyuanAI/XiyuanAI.exe`。保留 `_internal`、`examples` 和说明材料。CPU 配准与两图结构修复可离线运行；扩散生成需要另行准备 GPU 环境。

源码版：安装 Python 3.12 x64，在项目根目录运行 `./scripts/Setup.ps1 -Neural`，再执行 `.venv/Scripts/python.exe -m xiyuan_mvp.gui`。仅基础融合可不加 `-Neural`。

## 从导入到导出

1. 导入两张重叠充分的静态图片。多图按相邻重叠顺序排列；本机 RAFT 结构修复仅支持两图。
2. 保持“清晰融合”选中，点击自动配准。SIFT 失败时可尝试 LoFTR。
3. 查看羽化、泊松和修复底图。光照或清晰度判断不确定时，程序可能保留羽化结果。
4. 在接缝编辑页涂抹或擦除区域，支持撤销、清空、恢复自动区域。滚轮缩放，中键或右键拖动，双击适应窗口。
5. 选择“结构修复（本机，两图）”，保留“保护清晰细节”，运行修复。状态信息区分应用修复和保留底图；保留底图是有效结果。
6. 选中需要保存的对比页并导出 PNG。导出使用计算画布原始尺寸，界面缩放不改变结果尺寸。

通过“打开运行记录”加载 `run.json` 可恢复图像、参数和 Mask；文件会经过 SHA256 验证。输出目录含原始输入，分享运行记录前确认照片适合分享。

## GPU 实验

生成修复、Canny / Tile、LCM、Hybrid 和原尺寸分块属于可选实验。按 [复现与验收](复现与验收.md) 和 [Kaggle 说明](../../kaggle/README.md) 准备自己的账号。

桌面导出的 GPU ZIP 可由 `scripts/Invoke-GpuJob.ps1` 提交到自己的私有 Notebook；下载结果后打开返回的 `run.json`。Hybrid 可能根据结构收益和残差跳过扩散；界面会显示实际执行状态。

## 示例与限制

包内三个纹理示例用于配准、编辑与导出验收；`examples/motion-run/run.json` 使用已知几何，用于检查真实 RAFT 修复和保护开关，不代表未知场景配准效果。

大视差、移动物体、重复纹理可能失败；生成修复可能改变真实结构。原生 8 GB 显卡完整管线未验证；免费 T4 结果不能替代该结论。当前未完成真人盲评，不承诺任意照片画质提高。
